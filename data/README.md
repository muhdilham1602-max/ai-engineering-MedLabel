# Data directory

The project uses the official Rapid Bus KL static GTFS feed (`rapid-bus-kl`) from Malaysia's Open API, licensed CC BY 4.0. Retrieve the feed from https://api.data.gov.my/gtfs-static/prasarana?category=rapid-bus-kl and save its retrieval date, SHA-256 hash, source attribution and validation results in a manifest. Do not treat a changing feed as a fixed dataset. The provider documents a missing-trip caveat affecting approximately 2% of trips in `stop_times.txt`.
